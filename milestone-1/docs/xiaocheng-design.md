# 小澄 · 产品设计

> Smiling Tech 出品。
>
> 这份文件回答"为什么是这个产品"。决策时遇到分歧，回到这里。

---

## 一句话

**小澄是用 AI 做脚手架的当代六时书。**

帮被信息洪流打散的人，每天有几个时刻，停下来，看看自己。

---

## 一段话

我们看到一种人：聪明，敏感，对生活有想法。但每天被算法推送、群消息、AI 资讯、短视频、KPI 推搡着走。坐下来想"我今天想做什么"，发现这个问题已经很久没问自己了。

不是抑郁。不是 ADHD。不是任何标签。

是太多东西在替他做主。

我们想做一面镜子。每天几次轻轻问"你怎么样"。不评判，不规劝，只陪着记。三个月后告诉他："你看，这一段你走过了什么。"

镜子叫小澄。**澄**是水沉淀后的清。

---

## 不是什么

为了把"是什么"说清楚，先说"不是什么"。

| ❌ 不是 | 为什么 |
|---|---|
| AI 助手 | 助手做事，小澄陪人 |
| AI 朋友/伴侣 | 关系定位错位，监管和伦理风险都高 |
| 心理咨询替代品 | 我们绝不假装是治疗师 |
| 打卡 / habit tracker | streak 和惩罚思维与产品哲学相反 |
| 日记 app | 日记是单向输出，小澄是对话 |
| 笔记软件 | Notion 们已经做得很好 |
| 通用 chatbot | 没有人需要又一个 ChatGPT |

## 是什么（三层结构）

```
表层（用户来的理由）
├─ 知识管家：整理读到的、想到的
├─ 生活助理：处理待办、决策辅助
├─ 学习伙伴：长期跟随一个学习目标
└─ 健身教练：身体活动的同伴

  ↓ 每次使用，顺手沉淀

中层（用户留的理由）
├─ 六时书：每天几个时段的觉察记录
└─ 长期数据：行、思、情的模式累积

  ↓ 周期性显现

底层（产品魔法）
├─ 周洞见：这一周你走过了什么
├─ 月报告：这个月你的关键词
└─ 年时光册：你这一年怎么变化的
```

---

## 三个核心信念

### 1. 觉察先于改变

我们不教用户怎么"变好"。
我们帮用户**先看见自己**。

如果一个人能看清自己想要什么、卡在哪里、跟什么模式反复回旋——
他大概率会自己想出怎么改。

### 2. 脚手架，不是依赖

小澄是脚手架。脚手架的目的是让人自己站起来。

如果用户告诉我们"今天我自己想清楚了，不需要小澄"——产品做对了。

我们不刷留存率指标作秀。我们看用户的**自我效能感**是不是在涨。

### 3. 不评判是底线

用户说"我今天好废"。

主流 LLM 会说"不要这样想自己"——这是好心，但是评价。

我们说"嗯。能说说今天发生了什么吗？"——这是描述。

中国传统里有句话："道在屎溺"。你的全部，都值得被看见，不必被修正。

## 文化根基：六时书

### 当代源头：麦克·罗奇格西（Geshe Michael Roach）

当代华语世界所知的"六时书"，主要源自**麦克·罗奇格西**的传授与系统化。

罗奇格西是首位获得藏传佛教**格西学位**（佛学博士级学位）的西方人，曾在色拉寺梅扎仓接受多年系统训练。他通过《**能断金刚**》（The Diamond Cutter）一书与**金刚商道学院**（Diamond Cutter Institute）的体系，把这一源自藏传修心传统的日常实践，介绍给当代世界，对华语商业及自我成长圈层影响尤深。

罗奇格西所传六时书的核心：

- 一日分为多个时段，定时停下回看
- 观察对象：身、语、意三业
- 透过持续观察"种子"（习气模式），看见自己的因果
- 长期累积成可观察的自我图谱

### 更深的源头：藏传修心（Lojong）

罗奇格西所传承的，属于藏传佛教 **Lojong（修心）** 传统的一部分。修心的根本精神：把日常每一个当下，都转化为认识自己的机会。这一传统古已有之，罗奇格西的贡献在于把它**结构化、世俗化、可日常操作化**地介绍给非佛教徒的现代人。

### 小澄的取舍：删减，不扩展

| 借用 | 去掉 |
|---|---|
| 多时段定时回看的结构 | 业力 / 因果 / 种子的明确语言 |
| 行、思、感受三层观察 | 善 / 不善的判别维度 |
| 长期累积形成自我看见的素材 | 任何宗教身份认同 |
| 反思即修行的姿态 | "应该如何"的规范性指导 |

### 为什么去掉判别

罗奇格西的体系中，"种子"有善不善之分，是其因果哲学完整不可分的一部分。

但脱离完整修法语境，单独保留"判别"维度，会让现代普通人——尤其是已经被 KPI、自我要求、社交比较压迫的人——把六时书变成又一个**自我审判的法庭**。

我们的判断：对被信息洪流淹没的当代人，**先恢复看见自己的能力**比急着判断更重要。先看见，再让用户自己决定要不要做评价。

### 为什么用这个形式

- **结构感**：当代人最缺的，不是更多自由，是温和的结构
- **传承基础**：源自经过千年实践验证的修心传统，不是凭空发明
- **轻**：六时书不需要正坐入定，不需要长篇日记，不需要冥想 app 订阅
- **柔**：不像 GTD 是工具，更像一面安静的镜子

## 目标用户画像

> "被 AI 叙事/信息洪流/短视频支配的泛 ADHD 人群"

具体一点：

| 维度 | 描述 |
|---|---|
| 年龄 | 25-45 |
| 职业 | 知识工作者居多——程序员、设计师、产品、内容创作者、咨询、教师、自由职业 |
| 共性 | 智力高、信息接触量大、长期上网、对自己有期待 |
| 痛点 | 每天忙但说不清做了什么；想做的事老不开始；总在切换任务 |
| 不是 | 临床抑郁/焦虑（这些需要专业帮助）；老年人（产品形态不适合）；纯任务型用户 |
| 共鸣词 | "停下来"、"看看自己"、"慢一点"、"看见变化" |
| 触发场景 | 周末没干啥就过去了；半夜失眠回想这周；新年想改变什么但不知从何开始 |

## 产品形态约束

### 起步：微信服务号

- 主体：Smiling Tech
- 形态：文字对话 + 主动 nudge
- 优势：48h 客服消息窗口，足够异步、温和的节奏
- 限制：每月 4 条模板消息，不能滥用

### 不做：APP/小程序（起步阶段）

如果用户主动想要"独立 APP"、"小程序"、"网页"——再考虑。

理由：
- ADHD 用户的 APP 装机率低，公众号是低门槛
- 微信生态本身就是用户已在的地方
- 团队人力有限，先把灵魂打磨到位

### 后续可能：轻量 APP

如果做，**形态保留对话**——不变成 feed 流、社交网络、商业化堆砌。

## 核心交互节奏

### 一日

| 时段 | 默认 | 类型 |
|---|---|---|
| 卯 (7:00) | 开 | 一句意图 |
| 巳 (12:00) | 关 | 用户开则开 |
| 申 (16:00) | 开 | 一句状态 |
| 戌 (20:00) | 开 | 主要记录 |
| 子 (22:30) | 开 | 一日合一 |

每段不超过 3 分钟。最少完成只需一句话。

### 一周

周日 22:00 推送周洞见。一段文字+情绪曲线。**纯文字，不堆图表**（用户答 #3）。

### 一月

月初推送月报告。包含主题词、价值观演变、未达成意图、给下月一句问句。

### 一年

年初推送时光册。这一年你说过的话、走过的路、变化的样子。

## 不会做的事

| ❌ | 为什么 |
|---|---|
| 自由购买的"人格" / "皮肤" | 商业化破坏镜子的纯粹 |
| 用户排行榜 | 与人比 = 离开自己 |
| 任务 streak / 惩罚 | ADHD 不友好 |
| 大量 emoji / 卖萌 | 调性不对 |
| 复杂 onboarding | 启动门槛要尽可能低 |
| 推送广告 | 服务号绝不发非用户相关消息 |
| 用户数据训练模型 | 数据归用户 |
| 心理诊断 | 我们不是医生 |

## 名字

**小澄**

- 澄：水沉淀后的清。从"乱"到"看清"。
- 不用拟人化的"小爱"、"小冰"——避免情感投射陷阱。
- "小"是亲近，"澄"是定位。

英文名（如果出海）：**Cheng** 或 **A Pause**。

---

## 决策时的判断标准

遇到任何 trade-off，问三个问题：

1. **这个改动让用户更看见自己，还是更依赖小澄？**——选前者。
2. **这个改动让用户更慢下来，还是更刷得多？**——选前者。
3. **这个改动让用户多一份判断，还是多一份数据？**——选后者（数据）。
